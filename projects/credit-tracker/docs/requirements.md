# Requirements — Credit Tracker (ตรวจสอบความคืบหน้าการเรียน)
วันที่: 21/11/2026

## วัตถุประสงค์
นักศึกษา CS KMITL อยากรู้ว่าตัวเองเรียนไปกี่หน่วยกิตแล้ว ยังขาดวิชาไหน และจะเรียนจบตามหลักสูตรได้ไหม

## กลุ่มผู้ใช้ & บริบท
- นักศึกษาสาขา CS มจพ. (ปัจจุบัน ปี 3)
- ใช้บน Desktop browser เป็นหลัก (responsive รองรับ mobile ด้วย)
- ใช้คนเดียว ไม่มีระบบ login

## ฟังก์ชันหลัก (functional requirements)
1. **Upload PDF Transcript** — drag & drop หรือ click to browse ไฟล์ PDF ของ KMITL
2. **Parse ข้อมูลจาก PDF** — ดึงรายวิชา, หน่วยกิต, เกรดที่ได้
3. **เปรียบเทียบกับหลักสูตร CS KMITL** — map วิชาที่เรียนแล้วเข้ากับโครงสร้างหลักสูตร
4. **แสดง Dashboard** ประกอบด้วย:
   - หน่วยกิตรวมที่ผ่านแล้ว vs หน่วยกิตทั้งหมดที่ต้องเรียน
   - Progress bar / ผังแต่ละหมวดวิชา (วิชาศึกษาทั่วไป, วิชาชีพ, วิชาเลือก ฯลฯ)
   - รายวิชาที่ยังไม่ได้เรียน (ขาดอะไรบ้าง)
   - สรุปว่าจะจบได้หรือยัง / ยังขาดกี่หน่วยกิต
5. **จำ PDF ล่าสุด** ด้วย localStorage แต่ upload ใหม่ได้ทุกครั้ง

## ข้อมูล (input/output/เก็บข้อมูล)
- **Input**: ไฟล์ PDF Transcript จาก KMITL
- **Output**: Dashboard แสดงสถานะหน่วยกิตและรายวิชา
- **เก็บข้อมูล**: localStorage (บันทึกผล parse ล่าสุด ไม่ต้อง upload ซ้ำทุกครั้ง)
- **โครงสร้างหลักสูตร**: ฝังอยู่ใน JS เป็น static data (CS KMITL)

## Non-functional
- Responsive (Desktop หลัก, Mobile รอง)
- ภาษาไทยเป็นหลัก
- ทำงานออฟไลน์ได้ (หลัง parse แล้ว ไม่ต้องใช้ internet)
- ไม่ส่งข้อมูลขึ้น server ใดๆ ทั้งสิ้น (privacy)

## ขอบเขตที่ไม่ทำ (ตอนนี้)
- ไม่มีระบบ login หรือหลายผู้ใช้
- ไม่รองรับหลักสูตรอื่นนอกจาก CS KMITL
- ไม่มีการแก้ไขข้อมูลหลักสูตรผ่านหน้าเว็บ

## เกณฑ์ว่าเสร็จ (acceptance criteria)
- [ ] Upload PDF Transcript ของ KMITL แล้วแสดงข้อมูลรายวิชาได้ถูกต้อง
- [ ] Dashboard แสดง progress แต่ละหมวดวิชาพร้อม progress bar
- [ ] แสดงรายวิชาที่ยังขาดได้ชัดเจน
- [ ] สรุปว่าจะจบได้หรือยัง + เหลืออีกกี่หน่วยกิต
- [ ] เปิด browser ครั้งถัดไปยังเห็นข้อมูลเดิม (localStorage)
